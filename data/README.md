# Dataset

This project uses a real-world restaurant dataset containing 
~10,000 transaction records from 50 restaurant locations 
(January 2024 - January 2025).

## Features
- Date, Restaurant ID, Quantity Sold
- Actual Selling Price, Market Price
- Promotion Indicator, Special Event Indicator
- Weather Condition

## Note
The raw dataset is not publicly shared due to confidentiality 
of real business data.
